# StreamVista Cloud X — RCS Business Messaging Agent Description

## Overview
StreamVista Cloud X is a secure cloud platform for the media and entertainment industry. This RCS Business Messaging agent will be used to communicate with registered users, including Creators, Studios, Buyers, and authorized administrators.

## Legitimate Use Cases
The agent will be used for legitimate business communications such as:

- User registration and account verification
- One-time passwords (OTP) and login verification
- Studio and creator onboarding updates
- Production status notifications and alerts
- Delivery confirmations and screening invitations
- Billing and payment reminders
- Security alerts and policy updates
- Customer support and help-desk communications
- Service maintenance and feature announcements

## Target Audience
Registered users of the StreamVista Cloud X platform, including filmmakers, production companies, post-production studios, content creators, distributors, broadcasters, and media buyers.

## Consent & Compliance
- Messages are sent only to users who have registered with StreamVista Cloud X or have explicitly opted in.
- The service is intended for business communications only.
- Users can opt out of promotional communications at any time.

## Operator
The platform is owned and operated by StreamVista OPC Pvt. Ltd., India.
